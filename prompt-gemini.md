Este é o código de um app web que eu uso na minha barbearia para gerenciar clientes e um CRM. É um arquivo único (`index.html`) com HTML, CSS e JavaScript puros, sem framework e sem build. Os dados ficam no `localStorage`.

Regras para qualquer alteração:

1. Não reescreva o app do zero. Altere só o que eu pedir e devolva o arquivo completo atualizado.
2. Mantenha o visual (fundo escuro, dourado, fontes Instrument Serif e Manrope), o idioma (português do Brasil) e a estrutura de arquivo único.
3. Não use `alert`, `confirm` nem `prompt`. Use `toast()` para avisos e `askC()` para confirmar exclusões.
4. Nos atributos `onclick` e `oninput`, não use variáveis globais chamadas `form`, `name` ou `type`. O formulário usa a variável `FM`.
5. Depois de mexer nos dados, chame `save()` e depois `render()`.
6. Antes de entregar, confira se as telas Dashboard, Clientes, Ficha do cliente, Retornos, CRM, Registrar atendimento e Configurações continuam funcionando.

Quando eu pedir uma mudança, me diga em poucas linhas o que mudou e onde.
